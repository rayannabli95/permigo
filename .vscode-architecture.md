## Responsibility Layers

### Layer 1: Pages (`src/pages/`)
**What**: UI assembly, mounting, user interactions.
**Rules**:
- One file = one page/view.
- Export `mount(root, param)` function.
- Import services to fetch data.
- Attach event listeners here.
- Use `esc()` for any user data in `innerHTML`.

**Example** (`src/pages/quiz.js`):
```js
import { fetchQuiz, submitQuiz } from '@/services/quiz.js';
import { esc } from '@/utils/escape.js';

export async function mount(root, quizId) {
  const quiz = await fetchQuiz(quizId);
  
  const form = document.createElement('form');
  form.innerHTML = `
    <h1>${esc(quiz.title)}</h1>
    <div id="questions"></div>
    <button type="submit">Valider</button>
  `;
  form.addEventListener('submit', async (e) => {
    e.preventDefault();
    const result = await submitQuiz(quizId, getAnswers());
    root.innerHTML = `<p>Score: ${result.score}/20</p>`;
  });
  root.appendChild(form);
}
```

### Layer 2: Services (`src/services/`)
**What**: All Supabase calls, API logic, data fetching.
**Rules**:
- No DOM manipulation.
- Pure functions (fetch → return data).
- Handle errors, return or throw.
- All auth checks via RLS (on Postgres side).

**Example** (`src/services/quiz.js`):
```js
import { sb } from '@/auth/auth.js';

export async function fetchQuiz(quizId) {
  const { data, error } = await sb
    .from('quizzes')
    .select('*')
    .eq('id', quizId)
    .single();
  
  if (error) throw error;
  return data;
}

export async function submitQuiz(quizId, answers) {
  const { data, error } = await sb
    .from('quiz_submissions')
    .insert({ quiz_id: quizId, answers: answers })
    .select()
    .single();
  
  if (error) throw error;
  return data;
}
```

### Layer 3: Utils (`src/utils/`)
**What**: Reusable helpers, formatting, XSS mitigation.
**Rules**:
- Pure functions, no side effects.
- **XSS mitigation**: `esc(data)` escapes HTML, `richEsc(html)` allows safe tags.

**Example** (`src/utils/escape.js`):
```js
export function esc(str) {
  if (!str) return '';
  return String(str)
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#039;');
}
```

### Layer 4: Auth (`src/auth/`)
**What**: Supabase singleton, session management.
**Rules**:
- `sb` = Supabase client (import once, use everywhere).
- `cur-user()` = fetch logged-in user from session.

**Example** (`src/auth/auth.js`):
```js
import { createClient } from '@supabase/supabase-js';
import { env } from '@/config/env.js';

export const sb = createClient(env.SUPABASE_URL, env.SUPABASE_KEY);
```

### Layer 5: Router (`src/router.js`)
**What**: Hash-based routing, page mounting.
**Pattern**: `#/page/{param}` → calls `mount()` from `src/pages/page.js`.

**Example**:
```js
// #/quiz/123 → import quiz.js, call mount(root, '123')
```

## How to Add a New Feature

### Step 1: New Page
1. Create `src/pages/myfeature.js`:
```js
export async function mount(root, param) {
  // ...
}
```

2. Register in router (if not auto).

3. Link from another page: `window.location.hash = '#/myfeature/id'`.

### Step 2: New Service
1. Create `src/services/myfeature.js`:
```js
import { sb } from '@/auth/auth.js';

export async function fetchData(id) {
  const { data, error } = await sb.from('mytable').select().eq('id', id);
  if (error) throw error;
  return data;
}
```

2. Import in page:
```js
import { fetchData } from '@/services/myfeature.js';
```

### Step 3: New Table / Schema Change
1. Create migration in `supabase/migrations/00XX_myfeature.sql`:
```sql
CREATE TABLE mytable (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE mytable ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users see own data"
  ON mytable FOR SELECT
  USING (auth.uid() = user_id);
```

2. Run locally: `supabase migration up`.
3. Test, then deploy.

## Environment Setup

### `.env.local` (Vite, never commit)
```
VITE_SUPABASE_URL=https://xxx.supabase.co
VITE_SUPABASE_ANON_KEY=xxx
```

### `src/config/env.js`
```js
export const env = {
  SUPABASE_URL: import.meta.env.VITE_SUPABASE_URL,
  SUPABASE_KEY: import.meta.env.VITE_SUPABASE_ANON_KEY,
};
```


## Debugging

### "Build fails"
1. Check output: `npm run build 2>&1 | tail -20`.
2. Look for syntax/import errors.
3. Verify `esc()` is used for user data in `innerHTML`.

### "RLS blocks my request"
1. Check Postgres RLS policy.
2. Verify user is logged in: `cur-user()`.
3. Debug in DevTools → Network → Supabase request body & error.

### "Styling not updating"
1. Restart Vite: `npm run dev`.
2. Check CSS import path.
