## Top 10 implémenté dans cette branche (`feat/audit-top10`)

1. **P1 — WebP** : conversion des assets lourds référencés + maj des chemins
2. **S1-S4 — Migration Supabase** : revokes anon/triggers, search_path, index FK, drop index dupliqué
3. **P2 — vercel.json** : `Cache-Control: immutable` sur /skins /worlds /sounds /icons
4. **P4 — Prefetch idle** des routes chaudes élève (parcours, quiz, classement)
5. **R2 — Hero « welcome back »** accueil élève après ≥3j d'absence
6. **Engagement — PWA shortcuts** (appui long sur l'icône → Parcours / Quiz / Classement)
7. **UX — « Tout marquer lu »** sur la page notifications (si absent)
8. **P3 — Fonts** : `@import` bloquant → `<link>` parallèle
9. **P1bis — Landing** : `loading=lazy` + dimensions sur les images sous la ligne de flottaison
10. **U1 — Sweep emojis résiduels** → SVG (mes-coffres, exam-blanc, galerie, celebrate-screen, onboarding)

**Non retenus volontairement** (gros chantiers à planifier) : pipeline push complet (R1 — le plus rentable de tout l'audit, mérite sa propre PR + clés VAPID), consolidation des policies RLS (S5), Stripe (M1), Quiz du jour (R4/G1).
