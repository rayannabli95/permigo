Décisions figées respectées

  • Monnaie = validations — pas de gemmes ni boutique de skins.
  • Jalons = validations cumulées (3 → 300, MONITEUR_TIERS) — aucun autre type de jalon.
  • Palette = langage visuel élève (vert de marque) + accent pro discret (ton encre/sombre sur les surfaces moniteur).
  • Nav « Progression » — onglet unique regroupant Parcours · Trophées · Ligue (visible en tête des maquettes).

Contraintes techniques tenues

  • Mobile-first (≤ 480px), cibles ≥ 44px, prefers-reduced-motion géré.
  • Données réelles reprises de moniteur-levels.js et trophees-moniteur.js (rien réinventé).
  • Échappement esc() simulé dans le rendu ; en prod, esc() du projet sur toute donnée.

⚠️ Ce sont des maquettes statiques de présentation (cadre téléphone + ruban « Bénéfice moniteur »). Le code final sera du Vanilla JS intégré dans src/pages/enseignant/, branché sur Supabase. Rien ici n’est destiné au build de l’app.
